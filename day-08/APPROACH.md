# Day 08 — Approach

## Warm-up
Review controlled inputs, form button defaults, route ranking, URL parameter types, and search-parameter history behavior. Record predictions first, then compare them with observed behavior.

## Problem 1 — validateBooking
Use a pure TypeScript function with small field validators. Return only the first error for each field and test all assignment examples plus three additional cases.

## Problem 2 — Booking Form
Keep all six fields in one controlled values object. Derive validation errors on render, track touched fields and submit attempts, focus the first invalid field, and guard async submission.

## Problem 3 — Country Explorer
Parse every URL parameter, derive filtered and sorted country lists, clamp pagination after filtering, and use replace only for search typing.
