# Module 06 — Routing & Architecture

## Task 1 — Task details route

I will add React Router and create a route for each task using its project and task IDs.

The Details button will navigate to that route, and the details page will show the task information with a link back to its project.

Unknown task IDs will display a reusable EmptyState component.

## Task 2 — Project header

I will calculate the total and completed tasks for the selected project directly from the tasks array.

I will display the count and progress inside a Section, and show EmptyState when the project has no tasks.
